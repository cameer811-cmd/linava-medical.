# LINAVA Medical Wear

Independent medical scrubs and healthcare apparel storefront, adapted from AYOO Fashion.

## Setup
1. Create a separate Supabase project and apply the included SQL migrations in documented order.
2. Replace placeholder values in `config.js` with the new project's URL and publishable key.
3. Configure Auth administrator permissions, storage policies, and deploy on a separate Cloudflare Pages project.
4. Verify checkout, inventory and RLS before accepting live orders.

No AYOO production database connection or customer data is included.
